# specs 編集の規律

`specs/` はこのリポジトリの Source of Truth。その精度が実装・検証の往復回数を直接決める。

- 実装コードの丸写しをしない。構造・値・制約を仕様として記述する
- 「以前は◯◯だった」等の経緯注記は書かない
- デザインツール由来の原文・ID（レイヤー名・変数名等）は「正」であり書き換えない。タイポに見えてもスペルチェッカーには無視登録で対処する
- グローバル仕様 `specs/spec.md` に影響する変更は勝手に反映せず、提案として人間に確認する
